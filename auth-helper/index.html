Paseo Auth Helper

Railway 콘테이너에서 에이전트 인증을 도와주는 페이지입니다.

GitHub CLI

1. Railway Shell에서 아래 명령을 실행하세요:

gh auth login --web

2. 화면에 나오는 one-time code를 복사하세요.

3. https://github.com/login/device 에 들어가 코드를 입력하세요.

Claude Code

방법 A — API Key (가장 간편)

Railway Variables에 추가:

ANTHROPIC_API_KEY=sk-ant-...

방법 B — OAuth Token

로컬 컴퓨터에서 claude setup-token 실행 후 토큰을 Railway에 넣으세요:

CLAUDE_CODE_OAUTH_TOKEN=...

Codex (OpenAI)

방법 A — API Key

OPENAI_API_KEY=sk-...

방법 B — Device Code

Shell에서:

codex login --device-auth

저장 위치

인증 정보는 /home/paseo 볼륨에 저장됩니다. 재배포 후에도 유지됩니다.

이 페이지는 안내용입니다. 실제 로그인은 Railway Shell이나 Variables에서 진행하세요.
